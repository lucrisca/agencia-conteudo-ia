# Técnicas de Vídeo com IA (consolidado de produtos avaliados)

Este arquivo reúne técnicas e ferramentas específicas de geração de vídeo com IA,
identificadas ao avaliar produtos reais do mercado (Formação Bergamo Creators IA,
Mestre dos Prompts). Usar como referência para enriquecer a especificação de
montagem e a geração de prompts visuais.

## Ferramentas específicas de vídeo com IA (mercado atual)

- **Veo, Kling, Higgsfield, Sora**: geradores de vídeo por texto/imagem — cada um
  com pontos fortes diferentes (movimento de câmera, realismo, duração). Testar
  mais de uma ferramenta por tipo de cena antes de padronizar em uma só.
- **CapCut**: edição final, legendas, cortes — usado mesmo por quem não tem
  experiência prévia de edição, funciona bem inteiramente pelo celular.

## Personagem consistente (técnica de diferenciação)

O que separa produção amadora de profissional, segundo os produtos avaliados, é
manter o **mesmo personagem/rosto idêntico em cada vídeo** de uma série. Técnicas:
- Gerar uma "ficha visual" do personagem (ângulos, roupa, traços) e reusar como
  referência em cada novo prompt
- Especificar sempre os mesmos parâmetros de aparência ao gerar novas cenas
- Testar geração em lote (várias cenas do mesmo personagem de uma vez) para reduzir
  inconsistência entre prompts isolados

## Influencer/UGC ultra-realista

Criação de personagem hiper-realista para vender produto ou criar audiência sem o
criador precisar aparecer. Aplicações: TikTok Shop, infoproduto, venda de produto
próprio. Distinto de "clone digital" (ver `avaliador-produtos-ofertas` para a
distinção ética entre clone autoral e clone de terceiros).

## Vídeos cinematográficos e estilo de marca

- Estudar o "estilo" de marcas grandes (tom, cor, movimento de câmera) como
  referência de prompt, sem copiar propriedade intelectual específica
- Estilos citados como aquecidos no mercado: terror/ação com tom cinematográfico,
  histórias narrativas, animação estilo Pixar/anime, imóveis (transformar 1 foto de
  empreendimento em vídeo profissional)

## Estrutura de prompt para vídeo (o que os produtos ensinam)

Elementos que um prompt de vídeo bem estruturado geralmente especifica:
- Materiais e texturas da cena
- Iluminação (tipo, direção, intensidade)
- Estilo visual (realista, animação, cinematográfico)
- Ambiente/cenário
- Composição (enquadramento, ângulo de câmera)
- Detalhes específicos do personagem/produto

Uma ferramenta interna de "gerador de prompts" (estrutura fixa + IA de texto que
expande a ideia do usuário nesses elementos) reduz desperdício de créditos gerando
tentativa e erro — vale considerar como ferramenta interna da agência também.

## Aplicação nas skills da agência

- **Roteirista**: ao escrever roteiro para vídeo gerado por IA (não narração
  gravada), incluir marcação de estilo visual por cena, não só o texto falado
- **Editor de Vídeo**: usar a "ficha visual" de personagem consistente como parte
  padrão da especificação de montagem quando o canal usa personagem/influencer fixo
- **Designer de Thumbnail/SEO**: os mesmos princípios de prompt estruturado (luz,
  composição, estilo) valem para gerar a thumbnail, não só o vídeo em si

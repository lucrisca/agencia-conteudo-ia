# Workflows n8n

Exports JSON dos fluxos de automação, versionados aqui como backup/histórico fora do n8n em si.

- /por-canal: workflows específicos de cada canal (roteiro→voz→vídeo adaptado ao nicho)
- /compartilhados: pipeline principal e lógica de publicação multi-plataforma, reaproveitados por todos os canais
